# Transformation of Quadcopter

## 3D model

The project model is saved as a Bambu Studio 3MF project: [Transforming_Quad.3mf](Transforming_Quad.3mf).

GitHub cannot preview this 3MF file in the browser. To view or edit it:

1. Open [Transforming_Quad.3mf](Transforming_Quad.3mf) and choose **Download**.
2. Open the downloaded file in **Bambu Studio** (or choose **File → Open Project** inside Bambu Studio).

The model file remains in its original format so its project data is preserved.
